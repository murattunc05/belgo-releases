# Belgo — kurulum dosyaları

Bu repo yalnızca **Belgo**'nun Windows kurulum dosyalarını dağıtmak içindir; kaynak kod burada değildir.

## Kurulum

1. [Son sürüm](https://github.com/murattunc05/belgo-releases/releases/latest) sayfasından `Belgo-Setup-<sürüm>.exe` dosyasını indirin.
2. Çalıştırın. Yönetici izni gerekmez; kurulum eski sürümün üzerine yapılır, ayarlarınız korunur.

## Güncellemeler

Belgo 1.3.5 ve sonrası açılışta buradaki son sürüme bakar. Yeni sürüm varsa sağ altta haber verir; **Şimdi güncelle** dediğinizde kurulum dosyasını indirir, SHA-256 özetini doğrular, sessizce kurar ve Belgo'yu yeniden açar. Ayarlar › Güncellemeler bölümünden kapatılabilir.

Belgo dosyalarınızı internete göndermez; internete yalnızca bu sürüm denetimi için bağlanır.
